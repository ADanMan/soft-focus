# Soft Focus

Редакторский скилл для русскоязычной зумерской и альфа-речи: живые реакции, короткие диалоги, бытовой абсурд и хулиганский юмор. Основа редактуры — самостоятельная адаптация паттернов Humanizer. Комедия использует общие приёмы сценки и эскалации, без копирования индивидуального стиля конкретных комиков.

## Установка в Codex

Скопируйте папку репозитория в `~/.codex/skills/soft-focus`, затем откройте новую сессию Codex. Не заменяйте существующую папку без проверки локальных изменений.

Вызов: `$soft-focus перепиши этот текст живым русским чатным языком с острым юмором`.

Можно отдельно запросить альфа-регистр, подпись, короткую сценку или разбор паттернов. «Без шуток» отключает юмор для указанного текста.

## Содержимое

- `SKILL.md` — поведение и формат ответа.
- `references/patterns.md` — 29 редакторских, 8 речевых и 14 комедийных паттернов. Каждый содержит сигнал, действие, пример и ограничение.
- `references/lexicon.md` — русскоязычные контексты, ссылки и правила обновления.
- `agents/openai.yaml` — метаданные для Codex.

## Источники и обновление

[Мемотека](https://memepedia.ru/memoteka/) и [Омагад](https://memepedia.ru/category/omagad/) служат отправными точками для проверки новых выражений, их функций и русскоязычных контекстов. Предложка и месячные подборки дают дополнительные материалы. Скилл не копирует архив, галереи или номера комиков.

Текущий срез указан в `references/lexicon.md`. Наличие мема на русскоязычном сайте не доказывает его употребление всеми русскими подростками. Скилл различает общую чатную речь, мемный шаблон и инфоповод.

Еженедельное обновление настроено отдельно в локальном Codex. Сам репозиторий не запускает задания без этой настройки. Обновление проверяет новые источники, меняет только обоснованные пункты и сохраняет смысловые условия текста. При отсутствии новых подходящих материалов файлы не меняются.
